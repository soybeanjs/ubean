# ADR-0010 · 竞品北极星与「值得做」过滤器

- **状态**: accepted
- **日期**: 2026-08-21
- **关联**: [docs/roadmap.md](../roadmap.md)
- **决策者**: grill-with-docs 会话（Q1–Q5 均按推荐）

i18n 落地后需要一份半年规划，但「竞品有我们没有」会把路线图拖进 RSC、多 UI 运行时和再造引擎。公开站点的对比矩阵也把类型里写了、默认链没挂的能力打成满格 ✅。

**决定：**

1. **北极星（混合 D）**：对标 Next.js 的*能力*（流式 SSR、缓存层次、Server Actions、每路由渲染规则），**不对标 RSC**。对标 Nuxt 的*约定*（文件路由、模块、i18n、`routeRules`）。Astro 只对 Islands / 内容站。TanStack Start / Analog 用来找类型安全数据层等切口，不搬 React Query 或 Angular。
2. **「值得做」门槛**：必须先满足「用户习惯缺口」或「架构还债」之一，再叠加「性能」或「差异化」之一。单独「竞品有」→ **刻意不做 / 暂缓**。RSC、多 UI 运行时、再造 i18n 引擎、**拦截路由（`(.)` / `(..)` / `(...)` 目录约定）** = 刻意不做。
3. **权重**：架构健康 40% / 用户可见缺口 35% / 性能 25%。2026 Q4 还债，2027 H1 才堆用户可见缺口。
4. **范围**：只规划开源框架 ubean。studio / SoybeanAdmin 等独立产品的方案不进本仓库；本仓最多列 1–2 条开源侧开口（如脚手架契约），不排那些产品的里程碑。任务用 ID，不写人天。
5. **文档落点**：活的路线图归 `docs/`（开发任务型，ADR-0007）。落地后的任务清单删除，决策留 ADR。公开对比补丁归 `apps/docs` 中英 `framework-comparison.md`。任务清单不进站点。

## 补记 · 拦截路由按本 ADR 判为刻意不做（2026-09-17）

「文档承诺 vs 实际覆盖」审计的最后一项。当时的现状是：扫描器按 `(.)` / `(..)` / `(...)` 目录约定扫出 `interceptFrom` / `interceptTarget` 元数据、把页面注册成 `__intercept_*` 路由，但**全仓没有消费者** —— 「从 X 导航到 Y 时渲染拦截页」从未发生，拦截页只能落在它被清理后的路径上（一个谁也不会访问的废 URL），而公开对比矩阵却把它列在「已接线」里。

按第 2 条门槛逐项过：

- **架构还债**？否。**性能**？否。
- **差异化**？勉强站得住（Vue 生态没有对应物），但缺叠加项。
- **用户习惯缺口**？`(.)` 目录约定是 Next 专属；Nuxt（本仓的约定北极星）没有对应物，因此 Vue 用户不具备这个习惯。剩下唯一论据就是「Next 有」。
- 反过来还有两条**反对**理由：接线要求**故意的 SSR/客户端分叉**（服务端渲染完整页、客户端渲染对话框），与本仓在 J 缺陷里刚立起的「dev/产物、服务端/客户端两侧必须一致」原则冲突；且背景页会随拦截记录重挂载（Next 原生保留上下文），要做就得再叠一层页面缓存。
- 核心价值（URL 可分享、back 关闭对话框）用**已有的**并行路由 + 一个导航守卫在应用侧就能拿到，不需要框架约定。

**结论**：走第 2 条的「刻意不做」。清理动作与替代做法：

1. 移除约定的全部痕迹 —— 扫描器的标记段解析与两个元数据字段、生成器的 `__intercept_*` 路由注册、dev SSR 与产物入口里的两处同名分支、`serializePagesForEntry` 白名单里的两个字段、以及相关测试；
2. 扫到标记段**响亮失败**（抛错并给出替代做法），而不是静默退化成 `/feed/(.)photo/:id` 这种字面垃圾路径 —— 路由组正则只吞整段 `(group)/`，不吞 `(.)photo`；
3. 站点中英 `framework-comparison.md` 从「已接线」里删除该项，并在 `guide/pages-routing` 补「用对话框呈现另一条路由」的替代做法（并行路由 `@dialog/` + `<SlotView>` + 守卫决定何时以对话框呈现）。

若将来「Next 迁移平滑」被正式纳入北极星（那时「用户习惯缺口」论据才成立），可重新评估；机制已验证可行：同一 URL 两条路由记录、按路径解析落到真实页（直链/刷新渲染完整页）、按名字解析落到拦截记录（软导航渲染对话框），守卫需**先判断 `to.name` 前缀**防重定向环，且背景页必须是构建期静态可解的（在守卫里动态 `addRoute` 试过，实测进重定向环并丢参数）。
