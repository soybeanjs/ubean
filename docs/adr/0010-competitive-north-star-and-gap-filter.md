# ADR-0010 · 竞品北极星与「值得做」过滤器

- **状态**: accepted
- **日期**: 2026-08-21
- **关联**: [docs/roadmap.md](../roadmap.md)
- **决策者**: grill-with-docs 会话（Q1–Q5 均按推荐）

i18n 落地后需要一份半年规划，但「竞品有我们没有」会把路线图拖进 RSC、多 UI 运行时和再造引擎。公开站点的对比矩阵也把类型里写了、默认链没挂的能力打成满格 ✅。

**决定：**

1. **北极星（混合 D）**：对标 Next.js 的*能力*（流式 SSR、缓存层次、Server Actions、每路由渲染规则），**不对标 RSC**。对标 Nuxt 的*约定*（文件路由、模块、i18n、`routeRules`）。Astro 只对 Islands / 内容站。TanStack Start / Analog 用来找类型安全数据层等切口，不搬 React Query 或 Angular。
2. **「值得做」门槛**：必须先满足「用户习惯缺口」或「架构还债」之一，再叠加「性能」或「差异化」之一。单独「竞品有」→ **刻意不做 / 暂缓**。RSC、多 UI 运行时、再造 i18n 引擎 = 刻意不做。
3. **权重**：架构健康 40% / 用户可见缺口 35% / 性能 25%。2026 Q4 还债，2027 H1 才堆用户可见缺口。
4. **范围**：只规划开源框架 ubean。studio / SoybeanAdmin 等独立产品的方案不进本仓库；本仓最多列 1–2 条开源侧开口（如脚手架契约），不排那些产品的里程碑。任务用 ID，不写人天。
5. **文档落点**：活的路线图归 `docs/`（开发任务型，ADR-0007）。落地后的任务清单删除，决策留 ADR。公开对比补丁归 `apps/docs` 中英 `framework-comparison.md`。任务清单不进站点。
