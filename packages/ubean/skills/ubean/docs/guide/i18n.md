# Internationalization

ubean provides built-in internationalization (i18n) support.

## Setup

### Configure Locales

Create locale files in `src/locales/`:

```json
// src/locales/en.json
{
  "hello": "Hello",
  "welcome": "Welcome to ubean",
  "items": "no items | one item | {count} items"
}
```

```json
// src/locales/zh-CN.json
{
  "hello": "你好",
  "welcome": "欢迎使用 ubean",
  "items": "没有项目 | 一个项目 | {count} 个项目"
}
```

### Default Locale

Mark one locale as default:

```json
// src/locales/en.json
{
  "name": "English",
  "dir": "ltr",
  "messages": {
    "hello": "Hello"
  }
}
```

Or use `isDefault` field:

```json
// src/locales/en.json
{
  "isDefault": true,
  "hello": "Hello"
}
```

## Usage

### Basic Translation

```vue
<script setup lang="ts">
import { useI18n } from '@ubean/core';

const { t } = useI18n();

console.log(t('hello')); // "Hello"
console.log(t('welcome')); // "Welcome to ubean"
</script>

<template>
  <h1>{{ t('hello') }}</h1>
</template>
```

### Interpolation

```vue
<script setup lang="ts">
import { useI18n } from '@ubean/core';

const { t } = useI18n();

console.log(t('greeting', { name: 'World' }));
</script>
```

```json
{
  "greeting": "Hello, {name}!"
}
```

### Pluralization

Use pipe syntax for plural forms:

```json
{
  "items": "no items | one item | {count} items"
}
```

```typescript
t('items', { count: 0 }); // "no items"
t('items', { count: 1 }); // "one item"
t('items', { count: 5 }); // "5 items"
```

### Linked Messages

Reference other message keys:

```json
{
  "app": {
    "name": "ubean"
  },
  "welcome": "Welcome to @:app.name!"
}
```

```typescript
t('welcome'); // "Welcome to ubean!"
```

### Locale Switching

```vue
<script setup lang="ts">
import { useI18n } from '@ubean/core';

const { setLocale, locale } = useI18n();

setLocale('zh-CN');
</script>

<template>
  <button @click="setLocale('en')">English</button>
  <button @click="setLocale('zh-CN')">中文</button>
</template>
```

## Intl Formatting

### Date Formatting

```typescript
const { d } = useI18n();

d(new Date(), 'short'); // "1/15/24"
d(new Date(), 'medium'); // "Jan 15, 2024"
d(new Date(), 'long'); // "January 15, 2024"
d(new Date(), 'full'); // "Monday, January 15, 2024"
```

### Number Formatting

```typescript
const { n } = useI18n();

n(1234.56); // "1,234.56"
n(0.42, 'percent'); // "42%"
n(1234.56, 'currency'); // "$1,234.56"
```

### Currency Formatting

```typescript
const { c } = useI18n();

c(42.99, 'USD'); // "$42.99"
c(42.99, 'EUR'); // "€42.99"
c(42.99, 'CNY'); // "¥42.99"
```

### Relative Time

```typescript
const { relativeTime } = useI18n();

relativeTime(-1, 'day'); // "1 day ago"
relativeTime(2, 'hour'); // "in 2 hours"
relativeTime(-5, 'month'); // "5 months ago"
```

### List Formatting

```typescript
const { list } = useI18n();

list(['Apple', 'Banana', 'Cherry']);
// "Apple, Banana, and Cherry"
```

## Routing Strategy

Configure routing strategy in `ubean.config.ts`:

```typescript
import { defineConfig } from '@ubean/core';

export default defineConfig({
  i18n: {
    defaultLocale: 'en',
    strategy: 'prefix_except_default'
  }
});
```

### Strategies

- `prefix`: Always add locale prefix (`/en/about`, `/zh/about`)
- `prefix_except_default`: No prefix for default locale (`/about`, `/zh/about`)
- `no_prefix`: No locale prefix, detect from browser or header

### Localized Links

Use `<Link>` component for locale-aware navigation:

```vue
<script setup lang="ts">
import { Link } from '@ubean/core';
</script>

<template>
  <Link to="/about">About</Link>
</template>
```

### Switch Locale Path

Generate links for switching locales:

```typescript
import { switchLocalePath } from '@ubean/core';

// Switch to Chinese, keeping current path
switchLocalePath('zh-CN');

// Switch to English
switchLocalePath('en');
```

## Custom Detection

Detect locale from URL, header, or cookie:

```typescript
import { defineMiddleware } from '@ubean/core';

export default defineMiddleware(c => {
  // From URL
  const { locale } = c.req.param();

  // From header
  const acceptLanguage = c.req.header('Accept-Language');

  // From cookie
  const cookieLocale = c.req.cookie('locale');

  // Set locale
  if (locale) {
    c.set('locale', locale);
  }
});
```

## Missing Keys

Handle missing translation keys:

```typescript
const i18n = useI18n();

i18n.onMissingKey((locale, key) => {
  console.warn(`Missing key "${key}" for locale "${locale}"`);
});
```

## Best Practices

1. **Keep messages flat**: Avoid deep nesting
2. **Use namespaces**: Organize messages by feature
3. **Pluralize carefully**: Different languages have different rules
4. **Cache translations**: Message cache is built-in
5. **Handle RTL**: Use `dir` attribute for right-to-left languages
6. **Test all locales**: Always test with multiple languages
