# i18n API

## useI18n()

Access i18n instance.

```typescript
import { useI18n } from '@ubean/core';

const i18n = useI18n();
```

### Properties

| Property         | Type     | Description       |
| ---------------- | -------- | ----------------- |
| locale           | string   | Current locale    |
| defaultLocale    | string   | Default locale    |
| availableLocales | string[] | Available locales |

### Methods

| Method                             | Description          |
| ---------------------------------- | -------------------- |
| t(key, params)                     | Translate message    |
| setLocale(locale)                  | Set current locale   |
| d(date, style, options)            | Format date          |
| n(number, style, options)          | Format number        |
| c(number, currency, options)       | Format currency      |
| relativeTime(value, unit, options) | Format relative time |
| list(items, style, options)        | Format list          |
| onMissingKey(callback)             | Handle missing keys  |

## Translations

### Basic Translation

```typescript
const { t } = useI18n();

t('hello'); // "Hello"
t('welcome', { name: 'John' }); // "Welcome, John!"
```

### Nested Keys

```json
{
  "user": {
    "name": "User Name",
    "email": "Email Address"
  }
}
```

```typescript
t('user.name'); // "User Name"
t('user.email'); // "Email Address"
```

### Pluralization

```json
{
  "items": "no items | one item | {count} items"
}
```

```typescript
t('items', { count: 0 }); // "no items"
t('items', { count: 1 }); // "one item"
t('items', { count: 5 }); // "5 items"
```

### Linked Messages

```json
{
  "app": {
    "name": "ubean"
  },
  "welcome": "Welcome to @:app.name!"
}
```

```typescript
t('welcome'); // "Welcome to ubean!"
```

### Missing Keys

```typescript
const { t, onMissingKey } = useI18n();

onMissingKey((locale, key) => {
  console.warn(`Missing key "${key}" for locale "${locale}"`);
});

t('missing.key'); // Returns "missing.key" and warns
```

## Date Formatting

```typescript
const { d } = useI18n();

// Short format
d(new Date(), 'short'); // "1/15/24"

// Medium format
d(new Date(), 'medium'); // "Jan 15, 2024"

// Long format
d(new Date(), 'long'); // "January 15, 2024"

// Full format
d(new Date(), 'full'); // "Monday, January 15, 2024"

// Custom options
d(new Date(), 'short', {
  year: 'numeric',
  month: 'long',
  day: 'numeric'
});
```

### Format Styles

| Style  | Description   |
| ------ | ------------- |
| short  | Short format  |
| medium | Medium format |
| long   | Long format   |
| full   | Full format   |

## Number Formatting

```typescript
const { n } = useI18n();

// Decimal
n(1234.56); // "1,234.56"

// Percent
n(0.42, 'percent'); // "42%"

// Currency
n(1234.56, 'currency'); // "$1,234.56"

// Custom options
n(1234.56, 'decimal', {
  minimumFractionDigits: 2,
  maximumFractionDigits: 2
});
```

### Format Styles

| Style    | Description     |
| -------- | --------------- |
| decimal  | Decimal format  |
| percent  | Percent format  |
| currency | Currency format |

## Currency Formatting

```typescript
const { c } = useI18n();

c(42.99, 'USD'); // "$42.99"
c(42.99, 'EUR'); // "€42.99"
c(42.99, 'CNY'); // "¥42.99"

// Custom options
c(42.99, 'USD', {
  minimumFractionDigits: 0,
  maximumFractionDigits: 0
});
```

## Relative Time Formatting

```typescript
const { relativeTime } = useI18n();

relativeTime(-1, 'day'); // "1 day ago"
relativeTime(2, 'hour'); // "in 2 hours"
relativeTime(-5, 'month'); // "5 months ago"

// Custom options
relativeTime(-1, 'day', {
  style: 'long' // "one day ago"
});
```

### Units

| Unit    | Description |
| ------- | ----------- |
| year    | Years       |
| quarter | Quarters    |
| month   | Months      |
| week    | Weeks       |
| day     | Days        |
| hour    | Hours       |
| minute  | Minutes     |
| second  | Seconds     |

## List Formatting

```typescript
const { list } = useI18n();

// Conjunction (default)
list(['Apple', 'Banana', 'Cherry']);
// "Apple, Banana, and Cherry"

// Disjunction
list(['Apple', 'Banana', 'Cherry'], 'disjunction');
// "Apple, Banana, or Cherry"

// Unit
list(['Apple', 'Banana', 'Cherry'], 'unit');
// "Apple Banana Cherry"
```

### Styles

| Style       | Description                      |
| ----------- | -------------------------------- |
| conjunction | Items joined with "and"          |
| disjunction | Items joined with "or"           |
| unit        | Items joined without conjunction |

## Locale Management

### Set Locale

```typescript
const { setLocale } = useI18n();

setLocale('zh-CN');
```

### Get Current Locale

```typescript
const { locale } = useI18n();

console.log(locale); // "en"
```

### Get Available Locales

```typescript
const { availableLocales } = useI18n();

console.log(availableLocales); // ["en", "zh-CN"]
```

### Get Default Locale

```typescript
const { defaultLocale } = useI18n();

console.log(defaultLocale); // "en"
```

## defineLocale()

Define a locale.

```typescript
import { defineLocale } from '@ubean/core';

defineLocale({
  code: 'en',
  isDefault: true,
  messages: {
    hello: 'Hello',
    welcome: 'Welcome'
  }
});
```

### Options

| Option    | Type                   | Description              |
| --------- | ---------------------- | ------------------------ |
| code      | string                 | Locale code              |
| isDefault | boolean                | Default locale           |
| name      | string                 | Display name             |
| dir       | string                 | Text direction (ltr/rtl) |
| messages  | Record<string, string> | Translation messages     |

## addLocale()

Add a locale dynamically.

```typescript
import { addLocale } from '@ubean/core';

addLocale('es', {
  hello: 'Hola',
  welcome: 'Bienvenido'
});
```

## mergeLocale()

Merge messages into existing locale.

```typescript
import { mergeLocale } from '@ubean/core';

mergeLocale('en', {
  newKey: 'New Value'
});
```

## clearLocales()

Clear all locales.

```typescript
import { clearLocales } from '@ubean/core';

clearLocales();
```

## Best Practices

1. **Organize messages**: Group related messages together
2. **Use namespaces**: Use dot notation for organization
3. **Pluralize correctly**: Different languages have different rules
4. **Handle missing keys**: Register onMissingKey handler
5. **Cache messages**: Built-in caching improves performance
6. **Test all locales**: Always test with multiple languages
