# Internationalization

ubean provides built-in, zero-dependency internationalization (i18n) support via `runtime/i18n.ts` and `i18n-routing.ts`. No `vue-i18n` dependency required.

## Setup

### Configure Locales

Define locale configuration in `ubean.config.ts`:

```typescript
// ubean.config.ts
import { defineConfig } from 'ubean';

export default defineConfig({
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'zh'],
    strategy: 'prefix_except_default' // prefix | prefix_except_default | no_prefix
  }
});
```

### Locale Files

Create locale message files in `src/locales/` (JSON format):

```json
// src/locales/en.json
{
  "hello": "Hello",
  "welcome": "Welcome to ubean",
  "items": "no items | one item | {count} items"
}
```

```json
// src/locales/zh.json
{
  "hello": "你好",
  "welcome": "欢迎使用 ubean",
  "items": "没有项目 | 一个项目 | {count} 个项目"
}
```

### Locale Definition (Programmatic)

For programmatic registration, use `defineLocale`:

```typescript
// src/locales/index.ts
import { defineLocale } from 'ubean';

defineLocale({
  code: 'en',
  isDefault: true,
  messages: {
    hello: 'Hello',
    welcome: 'Welcome'
  }
});
```

| Option    | Type                   | Description              |
| --------- | ---------------------- | ------------------------ |
| `code`    | string                 | Locale code (e.g. `en`) |
| `isDefault` | boolean              | Default locale flag      |
| `name`    | string                 | Display name             |
| `dir`     | `'ltr' \| 'rtl'`       | Text direction           |
| `messages` | `Record<string, string>` | Translation messages   |

## Usage

### Basic Translation

```vue
<script setup lang="ts">
// useI18n is auto-imported from ubean/runtime/vue
const { t } = useI18n();

console.log(t('hello')); // "Hello"
</script>

<template>
  <h1>{{ t('hello') }}</h1>
</template>
```

### Interpolation

```json
{
  "greeting": "Hello, {name}!"
}
```

```vue
<script setup lang="ts">
const { t } = useI18n();
console.log(t('greeting', { name: 'World' })); // "Hello, World!"
</script>
```

### Pluralization

Use pipe syntax for plural forms:

```json
{
  "items": "no items | one item | {count} items"
}
```

```typescript
t('items', { count: 0 }); // "no items"
t('items', { count: 1 }); // "one item"
t('items', { count: 5 }); // "5 items"
```

### Linked Messages

Reference other message keys with `@:`:

```json
{
  "app": { "name": "ubean" },
  "welcome": "Welcome to @:app.name!"
}
```

```typescript
t('welcome'); // "Welcome to ubean!"
```

### Nested Keys

```json
{
  "user": {
    "name": "User Name",
    "email": "Email Address"
  }
}
```

```typescript
t('user.name'); // "User Name"
t('user.email'); // "Email Address"
```

### Locale Switching

```vue
<script setup lang="ts">
const { locale, setLocale } = useI18n();

async function switchToZh() {
  await setLocale('zh');
}
</script>

<template>
  <button @click="switchToZh">中文</button>
  <button @click="setLocale('en')">English</button>
  <p>Current: {{ locale }}</p>
</template>
```

## Intl Formatting

`useI18n()` exposes six Intl-based formatters:

### Date Formatting (`d`)

```typescript
const { d } = useI18n();

d(new Date(), 'short'); // "1/15/24"
d(new Date(), 'medium'); // "Jan 15, 2024"
d(new Date(), 'long'); // "January 15, 2024"
d(new Date(), 'full'); // "Monday, January 15, 2024"
```

| Style  | Description   |
| ------ | ------------- |
| short  | Short format  |
| medium | Medium format |
| long   | Long format   |
| full   | Full format   |

### Number Formatting (`n`)

```typescript
const { n } = useI18n();

n(1234.56); // "1,234.56"
n(0.42, 'percent'); // "42%"
n(1234.56, 'currency'); // "$1,234.56"
```

| Style    | Description     |
| -------- | --------------- |
| decimal  | Decimal format  |
| percent  | Percent format  |
| currency | Currency format |

### Currency Formatting (`c`)

```typescript
const { c } = useI18n();

c(42.99, 'USD'); // "$42.99"
c(42.99, 'EUR'); // "€42.99"
c(42.99, 'CNY'); // "¥42.99"
```

### Relative Time Formatting (`relativeTime`)

```typescript
const { relativeTime } = useI18n();

relativeTime(-1, 'day'); // "1 day ago"
relativeTime(2, 'hour'); // "in 2 hours"
relativeTime(-5, 'month'); // "5 months ago"
```

Supported units: `year`, `quarter`, `month`, `week`, `day`, `hour`, `minute`, `second`.

### List Formatting (`list`)

```typescript
const { list } = useI18n();

list(['Apple', 'Banana', 'Cherry']); // "Apple, Banana, and Cherry"
list(['Apple', 'Banana', 'Cherry'], 'disjunction'); // "Apple, Banana, or Cherry"
list(['Apple', 'Banana', 'Cherry'], 'unit'); // "Apple Banana Cherry"
```

| Style       | Description                      |
| ----------- | -------------------------------- |
| conjunction | Items joined with "and"          |
| disjunction | Items joined with "or"           |
| unit        | Items joined without conjunction |

## Routing Strategies

Configure routing strategy in `ubean.config.ts`:

```typescript
import { defineConfig } from 'ubean';

export default defineConfig({
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'zh'],
    strategy: 'prefix_except_default'
  }
});
```

### Strategies

- `prefix`: Always add locale prefix (`/en/about`, `/zh/about`)
- `prefix_except_default`: No prefix for default locale (`/about`, `/zh/about`) — default
- `no_prefix`: No locale prefix, detect from cookie or header

### Locale Detection Order

ubean detects locale in this order:

1. URL path prefix (if strategy is `prefix` or `prefix_except_default`)
2. Cookie (`ubean_locale` by default)
3. `Accept-Language` HTTP header
4. `defaultLocale` from config

On mismatch, ubean issues a 302 redirect and sets the `Content-Language` header.

### Localized Links

The global `<Link>` component automatically handles locale prefixes:

```vue
<template>
  <Link to="/about">About</Link>
  <!-- When locale=en (default), renders <a href="/about"> -->
  <!-- When locale=zh, renders <a href="/zh/about"> -->
</template>
```

### Locale in API Routes / Middleware

```typescript
// src/middleware/i18n-context.ts
import { defineMiddleware } from 'ubean';

export default defineMiddleware(c => {
  const locale = c.get('locale'); // Set by i18n routing middleware
  const acceptLanguage = c.req.header('Accept-Language');
  const cookieLocale = c.req.cookie('ubean_locale');
});
```

## SSR Hydration

ubean injects the current locale into SSR HTML via `<script id="__UBEAN_LOCALE__">`, enabling client-side hydration without re-fetching locale data. The `<html lang>` and `<html dir>` attributes are automatically synced.

## Missing Keys

Register a handler for missing translation keys:

```typescript
const i18n = useI18n();

i18n.onMissingKey((locale, key) => {
  console.warn(`Missing key "${key}" for locale "${locale}"`);
});

t('missing.key'); // Returns "missing.key" and triggers the handler
```

## Locale Properties

```typescript
const { locale, defaultLocale, availableLocales } = useI18n();

console.log(locale); // "en" (current)
console.log(defaultLocale); // "en"
console.log(availableLocales); // ["en", "zh"]
```

## Best Practices

1. **Keep messages flat or shallow-nested**: Avoid deep nesting
2. **Use namespaces**: Organize messages by feature (e.g. `nav.home`, `user.email`)
3. **Pluralize carefully**: Different languages have different plural rules
4. **Handle RTL**: Use `dir` attribute for right-to-left languages
5. **Test all locales**: Always test with multiple languages
6. **Cache messages**: Built-in message cache improves performance
